Для визуальной приёмки: проверить регистрацию и выход, вход клиента и сотрудника, создание обращения, комментарии и статусы, поиск, следующую страницу, пустые результаты и сетевую ошибку; проверить ширины 1440 и 390 px и клавиатурную навигацию. Сохранять только реальные скриншоты без персональных данных.

Для Docker: собрать образ, запустить Compose, создать сотрудника через stdin, создать обращение, перезапустить сервис и подтвердить сохранение данных. Не выполнять удаление тома с пользовательскими данными.
