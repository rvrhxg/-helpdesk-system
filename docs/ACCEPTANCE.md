# Состояние приёмки

Это текущие результаты, а не заявление о production-готовности.

| Проверка | Статус |
|---|---|
| Регистрация, вход, роли и отзыв сессии | Проверено HTTP-тестом |
| Изоляция обращений разных клиентов | Проверено HTTP-тестами |
| Изменение статуса и аудит | Проверено HTTP-тестом |
| Пагинация, фильтры, полная статистика | Проверено на 55 записях клиента |
| Ограничения JSON/Origin/частоты входа | Проверено негативными тестами |
| DOM-инициализация и открытие обращения | Проверено минимальным VM/DOM harness |
| Создание сотрудника и сохранение БД на диске | Автоматический интеграционный тест |
| Визуальная проверка desktop/mobile | Не выполнено |
| Реальные браузерные формы и dialog | Не проверено |
| Скриншоты интерфейса | Пока отсутствуют |
| Docker build и запуск с сохранением тома | Конфигурация есть, не проверено |
| GitHub Actions | Workflow есть, удалённый запуск не проверен |
| Отдельный репозиторий GitHub | Пока не опубликован |

Браузерная автоматизация остановлена защитой Computer Use: не удалось надёжно определить текущий URL. Обход ограничения не выполнялся. Docker и gh CLI не обнаружены; подключённый GitHub-инструментарий не предоставляет создание репозитория.

Для визуальной приёмки: проверить регистрацию и выход, вход клиента и сотрудника, создание обращения, комментарии и статусы, поиск, следующую страницу, пустые результаты и сетевую ошибку; проверить ширины 1440 и 390 px и клавиатурную навигацию. Сохранять только реальные скриншоты без персональных данных.

Для Docker: собрать образ, запустить Compose, создать сотрудника через stdin, создать обращение, перезапустить сервис и подтвердить сохранение данных. Не выполнять удаление тома с пользовательскими данными.
